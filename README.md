# SKS College of Nursing – College Management ERP

A modern, secure, and role-based College Management ERP designed specifically for **SKS College of Nursing**.

The application provides a clean, premium, Apple-inspired user experience while maintaining the functionality required for students, faculty, management, and accounts teams.

> **Learn with Compassion. Serve with Care.**

---

## 🎓 Overview

The SKS College of Nursing ERP centralizes academic, administrative, attendance, examination, financial, and communication workflows into a single platform.

The system uses **Role-Based Access Control (RBAC)** to ensure that every user sees only the features and information relevant to their role.

### Supported Roles

- 👨‍🎓 **Student**
- 👩‍🏫 **Faculty**
- 🏢 **Management / Admin**
- 💰 **Accounts**

# 🎨 Design System

The application follows a **modern, minimal, Apple-inspired design philosophy**.

The goal is to avoid the traditional crowded ERP appearance and provide a polished experience similar to modern education, healthcare, and banking applications.

### Design Principles

- Clean
- Minimal
- Professional
- Accessible
- Mobile-first
- Responsive
- Role-focused
- Consistent
- Fast
- Easy to navigate

### Visual Style

- Light-first interface
- Optional dark mode
- White and neutral backgrounds
- Healthcare-inspired blue/teal accent
- Dark navy/charcoal typography
- Soft shadows
- Rounded components
- Generous spacing
- Minimal borders
- Clear visual hierarchy
